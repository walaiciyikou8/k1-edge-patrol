# K1 智巡 · 边缘人脸识别巡检管理平台

面向 RISC-V 大赛（进迭时空 SpacemiT K1）的**边缘人脸识别巡检系统**管理端。
K1 端侧完成「人脸检测 → 512 维特征提取 → 1:N 比对 → 抓拍 → 扬声器播报」，
管理端完成人脸库维护、多点位巡检、告警处置与时间轴归档，数据可通过**华为云 OBS** 持久化。

## 快速开始

```bash
python build.py          # 合并 src/ 下的 CSS 与 JS → dist/index.html（单文件）
python -m http.server 8080 -d dist   # 本地预览：http://localhost:8080
```

> 单文件产物可直接双击打开，但浏览器的 WebCrypto 仅在 `https` / `localhost` 下可用，
> 因此**云端 OBS 直传功能必须在 https（或 localhost）环境使用**。

## 功能清单

1. **登录认证**：账号密码校验（哈希存储）、角色权限矩阵、8 小时会话、自动续期、锁定会话。
2. **数据看板**：4 项 KPI、告警趋势（24h / 7d / 30d）、**K1 双重算力面板**（8×X60 CPU 负载 + 2.0 TOPS NPU 占用 + FPS / 时延 / 温度）、点位分布、告警构成、最新告警、存储用量。
3. **人脸库管理**：列表 / 搜索 / 分类筛选 / 排序 / 分页、新增与编辑表单（照片上传或生成示例人像）、512 维特征向量可视化、命中记录、批量同步云端、CSV 导出。
4. **巡检点管理**：园区平面示意图 + 点位标记，**手动切换当前点位**（顶栏下拉 / 地图标记 / 列表按钮三处联动），模拟实时画面与端侧遥测，点位 CRUD，一键模拟 K1 抓拍。
5. **告警中心**：接收 K1 告警、状态流转（待处置 / 已派发 / 已确认 / 误报）、处置轨迹、扬声器播报文案、单帧 K1 指标、实时模拟接入、手动注入、Webhook 契约、CSV 导出。
6. **时间轴归档**：按日聚合、按点位 / 人员 / 关键词筛选、归档预览、**按时间顺序自动回放**、清单导出。
7. **华为云对接**：OBS 配置（SigV4 浏览器直传）、连接测试、全量同步、拉取云端快照、同步日志、K1 端对接规范与云服务清单。
8. **系统设置**：组织信息、告警阈值与冷却、播报模板（含变量预览）、账号管理、数据导入导出与重置。

## 华为云 OBS 接入

1. 在华为云控制台创建**对象存储桶**（如 `k1-patrol-demo`，区域 `cn-north-4`）。
2. 为该桶配置 **CORS**：允许本站来源的 `GET / PUT / DELETE / HEAD`，允许头 `Authorization, Content-Type, x-amz-*`，暴露头 `ETag`。
3. 在「华为云对接」页填入 Endpoint、Region、Bucket、AK、SK 与对象前缀，开启「启用云端」→ 保存配置 →「测试连接」。
4. 之后的状态变更会在 2.5 秒内自动推送快照；人脸照片与归档抓拍图也会上传到桶内。

对象结构：

```
k1-patrol/
├─ faces/F-1001_张伟.jpg                              # 人脸底库
├─ captures/20261030/20261030_142311_东门主入口_张伟.jpg  # 抓拍归档
└─ state/app-state.json                               # 管理端状态快照
```

> 演示环境的 AK/SK 仅保存在本机 localStorage；生产环境请改用华为云 **IAM 临时凭证（STS）**。

## K1 端对接

- 抓拍文件命名固定：`年月日_时分秒_点位名_人名.jpg`，管理端据此还原时间轴。
- 告警上报（等价于 `POST /api/k1/alerts`）：

```json
{
  "device": "K1S-2601-A01",
  "point": "P-01",
  "person": { "name": "张伟", "code": "F-1001" },
  "similarity": 0.937,
  "level": 3,
  "captured_at": "2026-10-30T14:23:11+08:00",
  "file": "20261030_142311_东门主入口_张伟.jpg",
  "object_key": "k1-patrol/captures/20261030/20261030_142311_东门主入口_张伟.jpg",
  "k1_metrics": { "cpu": 38, "npu": 52, "infer_ms": 21.5, "fps": 24.2 }
}
```

- **双重算力分工**：
  - CPU（8×X60 @1.6GHz）：MIPI 采集、H.264 硬解、图像缩放/色彩空间转换、告警封装、TTS 播报、OBS 上传。
  - NPU（2.0 TOPS，INT8）：RetinaFace 人脸检测 → 五点对齐 → 512 维特征提取 → 1:N 余弦比对。

## 数据说明

- 默认 **本地演示模式**：数据保存在浏览器 `localStorage`（key `k1_state_v1`），换设备不互通，可通过「系统设置 → 数据管理」导出 / 导入 JSON。
- 启用 **华为云 OBS** 后：对象与状态快照持久化到云端，K1 端与管理端共享同一份桶内数据。
